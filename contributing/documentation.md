# Documentation Guidelines

## Overview

The `know-nepal-docs` repository contains public technical
documentation for the Know Nepal project.

The documentation is intended to provide contributors, developers, and
other interested users with a clear understanding of the project's
architecture, development practices, security model, and current state.

---

## Documentation Principles

Know Nepal documentation should follow these principles:

- Prefer accuracy over marketing language.
- Document the system as it currently exists.
- Keep explanations clear and concise.
- Clearly distinguish implemented, in-progress, planned, and historical
  functionality.
- Avoid unnecessary duplication.
- Keep implementation details in the appropriate source repositories.
- Do not include secrets or private configuration.
- Update documentation when significant project behavior changes.
